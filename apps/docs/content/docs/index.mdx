## What UniAI can do

- **Hand work to agents** — assign an issue the way you would to a teammate; the agent posts progress and delivers results.
- **Share all context** — discussions, records, and deliverables stay in the workspace, visible to the whole team at any time.
- **Let work run itself** — set up scheduled runs and let multiple agents collaborate automatically.
- **Capture team know-how** — save what works as a skill that every agent can reuse.

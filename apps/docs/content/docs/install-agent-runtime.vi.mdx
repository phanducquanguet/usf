Một runtime cục bộ gồm hai phần: UniAI daemon và một công cụ lập trình AI mà daemon gọi được. Chỉ cần cài công cụ bạn định dùng — không cần đủ tất cả.

## 1. Chọn công cụ

Công cụ đã cài và đã đăng nhập thì không cần thiết lập gì thêm. Các công cụ khác nhau về model, MCP, khôi phục phiên và hỗ trợ skill; chi tiết xem [So sánh công cụ lập trình AI](/providers).

## 2. Đăng nhập trên máy của bạn

Sau khi cài, tự chạy công cụ một lần trong terminal và hoàn tất đăng nhập hoặc thiết lập nhà cung cấp model. Nếu công cụ không hoàn thành được yêu cầu trong terminal, các lần gọi từ daemon cũng lỗi y như vậy.

Với Reasonix, chạy `reasonix setup` và cấu hình provider cùng model mặc định trước khi khởi động daemon.

Với QwenPaw, chọn provider và model trong cấu hình riêng của QwenPaw. UniAI không ghi đè được model của QwenPaw lúc chạy.

Các thông tin đăng nhập đó do chính công cụ lưu cục bộ. UniAI không bao giờ nhận token đăng nhập từ Claude, Codex, Cursor hay bất kỳ CLI nào khác.

<Callout type="info">
Claude Code yêu cầu từ 2.0.0 trở lên, Codex từ 0.100.0, Copilot từ 1.0.0, Grok từ 0.2.89 và Qwen Code từ 0.20.0. Dưới phiên bản tối thiểu, daemon không đăng ký runtime tương ứng.
</Callout>

## 3. Xác nhận daemon tìm thấy lệnh

Trên macOS, Linux hoặc WSL, chạy:

```bash
command -v <command>
<command> --version
```

Trong Windows PowerShell, chạy:

```powershell
Get-Command <command>
<command> --version
```

Thay `<command>` bằng một lệnh trong bảng, ví dụ `claude`, `codex` hoặc `cursor-agent`. Lệnh đầu tiên in ra đường dẫn file thực thi.

Nếu terminal tìm thấy công cụ nhưng daemon chạy nền thì không, thường là hai bên đang dùng giá trị `PATH` khác nhau. Khởi động lại daemon, hoặc đặt đường dẫn tuyệt đối qua biến môi trường `MULTICA_<PROVIDER>_PATH` tương ứng.

## 4. Quét lại và xác nhận runtime online

Khởi động daemon bằng CLI:

```bash
uniai daemon start
```

Nếu daemon đang chạy sẵn, khởi động lại nó sau khi cài công cụ mới:

```bash
uniai daemon restart
```

Sau đó mở trang **Runtime** của UniAI. Công cụ hiện dưới máy tính tương ứng và ở trạng thái online. Giờ bạn có thể chọn runtime này khi tạo hoặc chỉnh sửa agent.

<Callout type="warning">
Daemon phải phát hiện được ít nhất một CLI được hỗ trợ sẵn thì mới khởi động. Các profile runtime tùy chỉnh chỉ đồng bộ sau khi daemon đã chạy, nên trên một máy trắng chúng không thể là điều kiện khởi động duy nhất.
</Callout>

## Không phát hiện được công cụ nào

Kiểm tra theo thứ tự:

1. Tự chạy công cụ trong terminal để xác nhận đã cài và đã đăng nhập xong.
2. Kiểm tra tên lệnh và đường dẫn thực tế bằng `command -v` hoặc `Get-Command`.
3. Chạy `uniai daemon logs -f` và tìm lỗi về phiên bản, đường dẫn hoặc xác thực.
4. Khởi động lại daemon để nó đọc lại môi trường hiện tại.
5. Quay lại trang **Runtime** và xác nhận máy tính lẫn công cụ đều online.

Nếu công cụ hiện online nhưng các lần chạy vẫn lỗi, mở bản ghi chạy của issue để xem chính xác lỗi mà CLI trả về.

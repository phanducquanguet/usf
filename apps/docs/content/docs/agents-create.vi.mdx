Tạo agent trước hết cần một [runtime](/daemon-runtimes) đang hoạt động. Runtime quyết định agent chạy trên máy nào và dùng công cụ lập trình AI nào; agent giữ danh tính lâu dài, chỉ dẫn và năng lực.

Trên trang **Agent** của không gian làm việc, bấm **New agent**.

## Điểm khởi đầu

Trang tạo agent đưa ra hai lựa chọn:

| Lựa chọn | Hợp khi |
|---|---|
| **Start blank** | Bạn đã biết rõ trách nhiệm của agent và muốn tự điền từng trường. |
| **Build with AI** | Mô tả mục tiêu trước, để Agent Builder hỏi những câu then chốt và sinh bản nháp. |

Build with AI cần một runtime đang online cho cuộc trò chuyện với Builder. Dù chọn cách nào, bạn đều xem lại và sửa được cấu hình cuối trước khi tạo.

![Hai điểm khởi đầu khi tạo agent: Start blank và Build with AI](/images/docs/quickstart-new-agent.png)

## Các trường bắt buộc

Tạo agent chỉ cần hai thứ:

- **Tên** — phải duy nhất trong không gian làm việc.
- **Runtime** — môi trường thực sự thực thi task.

Mọi trường khác cứ để mặc định rồi chỉnh sau khi tạo. Mặc định, chỉ người tạo chạy được agent mới.

## Mô tả và chỉ dẫn

**Mô tả** là phần giới thiệu ngắn cho cả nhóm. Nó chỉ hiện trong danh sách agent và trang chi tiết, không bao giờ đi vào prompt của công cụ lập trình AI.

**Chỉ dẫn** được cung cấp cho agent ở mỗi lượt chạy, thường nói rõ:

- nó chịu trách nhiệm gì và không chịu trách nhiệm gì;
- khi việc tới thì kiểm tra gì trước;
- nó được phép sửa những gì;
- giao kết quả theo cách nào;
- khi nào cần hỏi lại một thành viên trước khi làm tiếp.

Ví dụ:

```text
You review frontend pull requests.

Read the diff and related tests first, and check only:
- React and TypeScript correctness
- Accessibility
- Consistency with existing component patterns

Do not modify code directly. Post findings in an issue comment,
ordered by severity; when nothing blocks, state clearly that the change can merge.
```

## Thêm skill

Trong lúc tạo, bạn có thể chọn một hoặc nhiều [skill](/skills) từ không gian làm việc.

Skill hợp với phương pháp và tài liệu dùng lại giữa nhiều agent; yêu cầu lâu dài chỉ thuộc về riêng agent này thì đặt trong chỉ dẫn.

## Runtime, model và mức suy nghĩ

Mỗi runtime đã gắn sẵn với một công cụ lập trình AI. Chọn runtime xong, bạn chọn được model và mức suy nghĩ mà công cụ hỗ trợ; một số công cụ (như Codex) còn có bậc dịch vụ:

- Để trống thì áp dụng mặc định của runtime hoặc của CLI cục bộ.
- Đặt model thì agent dùng lựa chọn đó cho các task nó nhận từ đó về sau.
- Một số runtime tự quản lý model nên không hiện bộ chọn model.

Các công cụ khác nhau về model được hỗ trợ, khôi phục phiên, skill và năng lực MCP — xem [So sánh công cụ lập trình AI](/providers).

## Quyền truy cập

Quyền truy cập (Access) quyết định thành viên nào chạy được agent này (giao việc, @nhắc, hoặc chat):

| Quyền truy cập | Ý nghĩa |
|---|---|
| **Only me** | Chỉ bạn chạy được. Đây là mặc định. |
| **Entire workspace** | Mọi thành viên của không gian làm việc chạy được. |
| **Specific people** | Chỉ bạn và các thành viên được chọn chạy được. |

![Thiết lập Quyền truy cập: Only me, Entire workspace, Specific people](/images/docs/agent-access-settings.png)

Chỉ chủ của agent đổi được Quyền truy cập — admin của không gian làm việc thì không. `owner` và `admin` của không gian làm việc quản lý được phần cấu hình còn lại, nhưng không thể mượn vai trò quản trị để chạy những agent mình không được cấp quyền.

## Cấu hình sau khi tạo

Trên trang chi tiết của agent, bạn tiếp tục chỉnh được:

| Thiết lập | Tác dụng |
|---|---|
| **Giới hạn đồng thời** | Agent chạy được bao nhiêu task cùng lúc. Mặc định là 6; task vượt trần tiếp tục xếp hàng. |
| **Biến môi trường** | Tiêm biến khi công cụ lập trình AI khởi động. |
| **Đối số tùy chỉnh** | Nối lần lượt vào đối số CLI của công cụ lập trình AI. |
| **MCP** | Cung cấp cấu hình MCP server cho các công cụ lập trình AI hỗ trợ. |
| **Tích hợp** | Kết nối các dịch vụ ngoài mà agent này dùng được. |

Daemon chứa runtime cũng có trần đồng thời toàn cục (mặc định 20); mức đồng thời thực tế là con số nhỏ hơn trong hai trần.

Sửa cấu hình không thay đổi task đang chạy. Các task sau đó dùng cấu hình agent đã lưu tại thời điểm runtime nhận chúng.

## Biến môi trường và thông tin đăng nhập

Biến môi trường hợp với những thông tin đăng nhập phạm vi hẹp mà agent cần lúc chạy, ví dụ API key chỉ đọc hay token một phạm vi.

<Callout type="warning">
**Giá trị `custom_env` được lưu dạng plaintext trong cơ sở dữ liệu server của UniAI** — chúng không phải dữ liệu "chỉ nằm trên máy này". Endpoint list và chi tiết agent không còn trả về bất kỳ giá trị env nào, chỉ một con số đếm; chỉ `owner` và `admin` của không gian làm việc mở khóa và sửa được giá trị, và mọi lần đọc hay thay đổi đều để lại bản ghi kiểm toán. Agent đang chạy không thể gọi các endpoint quản trị để đọc biến của agent khác.
</Callout>

Đừng dùng mật khẩu quản trị cơ sở dữ liệu production hay các thông tin đăng nhập lâu dài, giá trị cao khác.

Các biến runtime trọng yếu như `PATH`, `HOME` và `MULTICA_*` không ghi đè được ở đây.

## Đối số tùy chỉnh và MCP

Đối số tùy chỉnh được truyền cho công cụ lập trình AI dưới dạng mảng, từng mục một, không qua khai triển shell. Đối số có hợp lệ không là chuyện của công cụ; cấu hình model đã có trường riêng thì không cần lặp lại ở đây.

Cấu hình MCP có thể chứa token; quy tắc lưu trữ và hiển thị của nó giống biến môi trường. Chỉ những runtime hỗ trợ cấu hình MCP được quản lý mới hiện mục này; công cụ không hỗ trợ MCP không tự có thêm năng lực chỉ vì một cấu hình được lưu.

## Nhân bản agent

Nhân bản mang theo phần lớn cấu hình đang dùng trừ tên, gồm chỉ dẫn, skill, đối số tùy chỉnh, avatar, giới hạn đồng thời và thiết lập Quyền truy cập. Model, mức suy nghĩ và bậc dịch vụ cũng đi theo; nếu runtime gốc không khả dụng và bản sao buộc phải chuyển sang runtime khác, ba giá trị này bị xóa và phải chọn lại.

Giá trị biến môi trường và cấu hình MCP không bao giờ được sao chép, phải đặt lại trên agent mới. Nhân bản giữ nguyên runtime và thiết lập Quyền truy cập của agent gốc.

## Tạo bằng CLI

```bash
uniai agent create \
  --name "Frontend Reviewer" \
  --runtime-id <runtime-id> \
  --description "Reviews frontend pull requests" \
  --instructions "Read the diff and tests first; post review conclusions only as issue comments."
```

Plaintext trong đối số dòng lệnh sẽ nằm lại trong lịch sử shell; stdin và file được giới hạn quyền thì không.

Khi đã có một agent cấu hình tương tự, sao chép thẳng:

```bash
uniai agent copy <agent-id>
```

Mặc định bản sao ở lại cùng runtime; thêm `--runtime-id` để chuyển sang runtime khác, và khi đó phải kèm `--model`. Biến môi trường, cấu hình MCP và `runtime_config` không bao giờ được sao chép; riêng liên kết runtime thì được giữ. Cờ đầy đủ tại [Dùng CLI](/cli).
